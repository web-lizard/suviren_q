# Bookender Studio 2.0.0

Bookender Studio 2.0.0 превращает прежние разрозненные книжный и
видеоредактор в единую локальную многопроектную экосистему. Каждая книга
получает собственные главы, настройки голоса, версии озвучки, медиаматериалы
и видеомонтаж, а переключение проектов больше не смешивает их данные.

## Главное

- полноценный редактор книг с главами, поиском и автосохранением;
- динамический каталог TTS-голосов, пресеты, проба голоса и озвучка всей книги;
- независимые версии MP3 для каждой главы со встроенным плеером;
- передача актуальных озвучек и структуры книги в видеоредактор;
- безопасный импорт legacy-книг с сохранением пользовательских правок;
- SQLite-миграции, резервные копии и структурированный технический журнал;
- обновлённый золотой интерфейс книги и восстановленная иконка приложения.

## Исправления релиза

Компонент `edge-tts` теперь проверяется и при необходимости устанавливается
самим launcher. Воспроизведение пробы и готовых версий больше не прерывается
конфликтующими запросами `load()` и `play()`: плеер ждёт готовности MP3 и
запускает только актуальный источник.

Пользовательские проекты и аудиофайлы остаются локальными. Сетевому
TTS-провайдеру текст передаётся только после явного запуска озвучки.
