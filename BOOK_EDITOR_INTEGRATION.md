# Book editor integration

Вкладка «Книга» встроена в тот же Vue/FastAPI desktop runtime, что и
видеоредактор. Отдельный PHP-сервер не требуется.

Функции:

- глобальный project picker и создание книги;
- список, создание, переименование, архивирование и reorder глав;
- компактный legacy-inspired список глав и рабочий текстовый редактор;
- сворачиваемый/скрываемый инспектор, состояние которого хранится в localStorage;
- debounce autosave со статусами changed/saving/saved/error;
- защита сохранения при смене главы, проекта и закрытии;
- metadata и отдельные для проекта TTS settings;
- динамический список голосов Edge TTS с управляемым fallback-списком;
- пресеты скорости/тона и короткая проба выделенного текста;
- фоновая озвучка главы через Edge TTS;
- source text hash и индикатор устаревшей озвучки;
- версии озвучки, активная версия и встроенный нижний плеер;
- актуальные audio assets доступны при создании video edition.

API находится под `/api/projects`. Frontend не пишет SQLite и не дублирует
правила порядка/хэшей: это делает `ProjectRepository`.

«Озвучить главу» создаёт `tts_jobs` и сразу возвращает управление. Фоновый
worker сохраняет новую версию MP3 в `user_data/projects/<uuid>/audio` и
создаёт `audio_assets`. Старые версии не перезаписываются. Проба хранится в
`temp` проекта и не регистрируется как озвучка главы. Полный текст главы не
попадает в structured log.

Edge TTS является сетевым провайдером: текст отправляется ему только после
явного нажатия «Проба голоса», «Озвучить главу» или «Озвучить всю книгу».
Пользовательский интерфейс показывает безопасное сообщение, а исходная
техническая ошибка записывается в `user_data/logs/bookender.log`.
