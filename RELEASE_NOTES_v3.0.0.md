# Book Wunderwaffe Studio 3.0.0

Версия 3.0 возвращает приложению историческое название
**Book Wunderwaffe Studio** и закрепляет единый рабочий процесс книги,
озвучивания и видеокниги.

## Главное

- единая многопроектная библиотека книг и видеомонтажей;
- устойчивое озвучивание длинных глав с живым индикатором выполнения;
- полноценный аудиоплеер и передача активных озвучек в видеоредактор;
- отдельное изображение для каждой главы;
- опциональный вывод читаемого фрагмента текста в видео;
- экспорт всей книги, текущей главы или поглавного ZIP с медиа;
- пурпурный книжный редактор и компактная панель основных действий.

## Совместимость

Существующая база `user_data/bookender.db`, проекты, аудиоверсии и видеомонтажи
сохраняются без переименования и автоматически открываются в версии 3.0.0.
